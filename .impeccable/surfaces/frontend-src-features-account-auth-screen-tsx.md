# Supporting task screens

Mode: Operate. Follow the [visual system](../../DESIGN.md) and [service boundaries](../../docs/status.md). Use compact forms, readable lesson rows and direct task labels. Keep source illustrations separate from form controls. Appearance stays in Settings; period is contextual rather than a universal filter.

Preserve return destinations, guest activity, bookmarks and storage identity. Preview forms must explain disconnected services without claiming successful authentication, payment or generation.

[Offer requirements](../../docs/product/account-and-offer.md#premium-selection) define the next Premium-selection flow. A visual selection is not an entitlement. Verify phone/desktop layouts, themes, keyboard/focus and complete error/return paths.
