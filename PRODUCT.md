# Product context

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

The active application is the Next.js/React and TypeScript package in `frontend/`; shared product/technical docs remain at the repository root. It is a local-first prepared-content frontend; the rejected separate prototype has been removed. Installed dependencies and commands live in [package.json](frontend/package.json). [Current state](docs/status.md) distinguishes working features, explicit previews and planned services.

## Users and purpose

Curious adults, often beginners, explore history through visual, interactive stories with inspectable evidence. English first, mobile-first responsive web; any historical era can be explored. The provisional working name is Interactive History.

## Product mechanism

The current renderer accepts validated lesson data: nine content families and 18 teaching presets, with image inspection, maps, timelines, comparisons, processes and native 3D. Four prepared storyboards demonstrate the shared system. [Scene contracts](docs/technical/scenes.md) and the [authoring guide](docs/technical/lesson-authoring.md) are the implementation references.

Research and generation will compose these supported forms inside the website. Live generation, persisted evidence/readiness, production narration, accounts, personal trails and community services remain planned. Historical decisions and relationship diagrams need supported contract/renderer extensions. Storytelling, meaningful interaction and inspectable sources distinguish the experience from a chat lesson.

## Confirmed constraints

Public browsing/playback is account-free. The frontend already supports device-local progress, exact paragraph bookmarks, whole-story saving, My space, four themes, larger text and reduced motion. Read and optional browser Listen use the same narrative. Cross-device account sync is future work.

Production stories target roughly 15–20 minutes with optional detours; the three-chapter showcases demonstrate composition rather than prove that duration or production audio. Detailed product direction lives in [experience](docs/product/experience.md), [library](docs/product/library.md), and [account/offer](docs/product/account-and-offer.md).

Visual concepts in `docs/visuals/` and `design-explorations/` are illustrative, not fixed layouts, verified history, or production assets. Latest user feedback outranks them. Pricing, final identity, narrator voice and exact visual treatments remain open. Keep README empty and deployment deferred.

## Accessibility

Readable mobile text, keyboard/focus support, adequate contrast, reduced motion, transcripts/captions, text equivalents for maps, and no essential meaning conveyed only through sound or color. Current rendered and audio verification remains pending; see [status](docs/status.md).
