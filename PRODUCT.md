# Product context

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Next.js/React and TypeScript in `frontend/`. [Status](docs/status.md) distinguishes working frontend behavior from planned services; manifests and lockfiles own installed dependencies.

## Users and purpose

Curious adults, often beginners, learn across subjects through interactive visual explanations. English first, mobile-first responsive web. Learn is the provisional wordmark; final naming is open. Existing `story` identifiers and routes remain compatible.

## Product mechanism

A learner asks a question, discovers an existing lesson or requests a new explanation. Agents will compose evidence-backed content using supported data contracts and interaction models. Formats serve the subject: inspect an image, manipulate a structure, follow a process or change an input and see the result. The [product map](docs/design.md) owns behavior; [learning engine](docs/technical/learning-engine.md) owns supported mechanics.

## Constraints

Public browsing, playback, sources and accessibility remain free. New generation requires verified identity and bounded allowances. The local frontend includes personal learning trails and task-specific provider preferences. The commercial offer is defined in [account and offer](docs/product/account-and-offer.md); unresolved prices and benefits stay explicit. Keep user actions honest about connected services. Source imagery retains attribution and its original colors. Visual rules live in [DESIGN.md](DESIGN.md).
