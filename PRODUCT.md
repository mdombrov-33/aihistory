# Product context

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

The active application is the Next.js/React and TypeScript package in `frontend/`; shared product/technical docs remain at the repository root. It is a local-first prepared-content frontend; the rejected separate prototype has been removed. Installed dependencies and commands live in [package.json](frontend/package.json). [Current state](docs/status.md) distinguishes working features, explicit previews and planned services.

## Users and purpose

Curious adults, often beginners, learn across subjects through interactive visual explanations. A question may concern science, music, technology, mathematics, nature, history or another teachable subject. English first, mobile-first responsive web. The product name is undecided; the existing HISTORY branding is a legacy placeholder, not a subject constraint.

## Product mechanism

Agents will compose coherent learning experiences from supported mechanics and evidence. Learners can manipulate a system, change an input, inspect a structure, follow a process and connect the result with a clear explanation. Formats serve the teaching goal; maps, timelines, imagery and 3D are optional materials rather than compulsory features. Public copy can use lesson or experience; the code and current routes still use story.

The working prepared renderer supports 15 families and 24 presets, including 3D assemblies, thin-lens and pendulum experiments, harmonic sound, Boolean networks, reversible packet travel and build/test logic. Nine prepared lessons exercise the shared system. [Learning engine](docs/technical/learning-engine.md) records current behavior, limitations and future ideas; [scene contracts](docs/technical/scenes.md) and [authoring](docs/technical/lesson-authoring.md) own the content seam.

Live generation, persisted evidence/readiness, production narration, accounts, personal trails and community services remain planned. Broad subject scope does not mean arbitrary scientific simulations are already supported: a new computational model needs implementation and validation. The current exploration order is engine and examples, documentation alignment, then homepage design. Earlier history-only homepage concepts are not the next homepage brief.

## Confirmed constraints

Public browsing/playback is account-free. The frontend already supports device-local progress, exact paragraph bookmarks, whole-story saving, My space, four themes, larger text and reduced motion. Read and optional browser Listen use the same narrative. Cross-device account sync is future work.

Production stories target roughly 15–20 minutes with optional detours; the prepared showcases demonstrate mechanics and composition rather than prove that duration or production audio. Detailed product direction lives in [experience](docs/product/experience.md), [library](docs/product/library.md), and [account/offer](docs/product/account-and-offer.md).

Visual concepts in `docs/visuals/` and `design-explorations/` are illustrative, not fixed layouts, verified subject matter, or production assets. Latest user feedback outranks them. Pricing, final identity, narrator voice and exact visual treatments remain open. Keep README empty and deployment deferred.

## Accessibility

Readable mobile text, keyboard/focus support, adequate contrast, reduced motion, transcripts/captions, text equivalents for maps, and no essential meaning conveyed only through sound or color. Current rendered and audio verification remains pending; see [status](docs/status.md).
