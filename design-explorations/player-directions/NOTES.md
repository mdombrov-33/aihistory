# Lesson-player alternatives

Status: four generated visual proposals; awaiting user choice. These are not application screenshots and are not approved implementation references yet. The running app was not modified for this exploration.

Open `index.html` directly in a browser. It has no server, build or network dependency. Each image opens at full resolution. Exact prompts are in `prompts/`; each PNG has a provenance sidecar. Generated with the built-in image-generation tool, using the previously selected Worlds board as an identity reference.

## What this round must resolve

The user rejected a static preview image carrying repetitive low-value selection widgets, followed by disconnected long prose. The scene must teach through substantial readable history, distinct purposeful visual material and self-paced discovery. A decorative image plus arbitrary buttons does not satisfy this brief.

| Alternative | Main learning mechanism | What changes as the learner advances | Main tradeoff |
| --- | --- | --- | --- |
| Inside the scene | Spatial inspection of a reconstructed place | Scene composition, selected historical feature and explanatory passage | Requires deliberate original artwork and meaningful annotations for each scene |
| Follow the route | Geographic and chronological relationships | Route stage, object, location focus and historical explanation | Appropriate for movement and networks; cannot govern every chapter |
| Open the evidence | Inspecting a source or object alongside interpretation | Document/object, annotation and explanation of evidence limits | Needs genuinely sourced material and honest reconstruction labels |
| Illustrated chapters | A coherent substantial narrative supported by original visuals | Text and artwork turn together as a passage | Less exploratory; maps and evidence can supply variation where useful |

## Shared behavior proposals

- Reading is visible in the core composition. There is no separate wall of text below a decorative hero. A chapter can contain multiple substantial passages; a single screenshot is not the entire chapter.
- Narration is optional. Pause, seek and move forward immediately. Changing passages keeps Read and Listen aligned. No compulsory audio wait or automatic movement while inspecting an artifact.
- Source links are accessible without treating generated imagery as archival evidence. Exact labels, source quotations, geography and chronology must be validated independently of generated mockups.
- Keep compact Chapters, bookmark, Sources and sound controls. No quiz, rating or arbitrary choice is required to move forward.
- These PNGs show desktop compositions. Mobile behavior is described in the gallery, not demonstrated or verified by these renders. A selected direction needs an explicit mobile composition before implementation.

## Recommendation to discuss

Use illustrated chapters for the narrative backbone, with route and evidence scenes where their forms teach more clearly. Use spatial exploration selectively when a real place and its organization are the subject. This is a proposal, not a recorded user decision.

Do not implement until the user chooses, combines or revises these concepts. Preserve the exact selected composition as the future reference rather than loosely translating its mood.

## Do not literalize generated details

The first and fourth images invent a precise century for their reconstructed architecture; that label is not verified. The map image's period stops and pins are illustrative, and the three objects are alternative topics, not a causal chain in which silk becomes paper. The evidence image's script is invented and cannot support a translated quotation. Final narration controls must show one coherent playback state, even if generated Read/Listen states differ. These limitations concern the mockup details; the composition and learning mechanism are what this round asks the user to select.
