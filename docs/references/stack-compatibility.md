## Integration constraints

Better Auth's [Drizzle adapter documentation](https://better-auth.com/docs/adapters/drizzle) uses the separate `@better-auth/drizzle-adapter` package with PostgreSQL provider `pg`. Generate auth tables/relations from the pinned auth configuration and plugins using the corresponding pinned CLI, review the resulting schema, and include it in the application's Drizzle schema. Drizzle Kit generates and applies the single reviewed SQL migration history; do not introduce a competing auth migration owner. Explicitly map renamed/plural tables. The default adapter uses Relations v1; the Relations v2 entry point is separate, so keep the stable ORM and default adapter together initially. Resolve the CLI package/version before executing schema generation; documentation's floating `auth@latest` is not a project pin.

[Next 16 removes `next lint`](https://nextjs.org/docs/app/api-reference/config/eslint), and [build no longer runs lint](https://nextjs.org/docs/app/getting-started/installation). Invoke Oxlint directly in the agreed `lint` script and in `check`. Oxlint's [built-in plugins](https://oxc.rs/docs/guide/usage/linter/plugins) include `nextjs`, `react`, and `jsx-a11y`; enabling plugins only exposes rules, and supplying a plugin list replaces defaults. Explicitly enable Hooks rules and audit coverage. Its [typed backend](https://oxc.rs/docs/guide/usage/linter/type-aware) follows TypeScript 7 configuration rules; use `--type-aware`, retain separate strict `tsc --noEmit`, and avoid removed options such as `baseUrl`. Do not assume ESLint configuration or automatic Next integration applies.

## Remaining setup gate

Before adding the remaining backend stack, verify its unresolved package publications/peers above, select the PostgreSQL driver and auxiliary test/type-package pins, resolve immutable image digests, and review release notes for the selected toolchain. Then prove a frozen install, read-only formatting/lint/types, a Next production build, one client test, real PostgreSQL migrations/auth flow through Mailpit, and one mobile browser journey. None of these application checks ran during this documentation research. This list does not authorize scaffolding, installation, or deployment.
