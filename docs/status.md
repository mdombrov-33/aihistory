# Current state

## Product direction

Interactive learning across subjects is the accepted scope; history has no required priority. After two rejected design rounds were removed, the user approved an immersive homepage direction for implementation in the actual frontend. The current homepage combines question entry, real local continuation, source-image inspection, a sourced Moon model, a flat geographic connection map and a curated prepared collection. All four themes remain available in Settings; there is no navbar theme picker. “Learn” is a provisional wordmark; the final product name remains open. [Learning engine](technical/learning-engine.md) records working additions and ideas still to explore.

## Implemented frontend

The Next.js/React package in `frontend/` is the only application. Shared docs, agent guidance and design references stay at the repository root. The [frontend navigation guide](../frontend/DEVELOPMENT.md#start-here) maps the consolidated `features/lesson/` engine, controls, content, guest state and test suites. Installed versions and runnable commands live in [package.json](../frontend/package.json) and [development](technical/development.md). Styling now defaults to Tailwind utilities and component variants; global styles contain tokens and document/accessibility defaults, with coordinated visual CSS beside its feature. The root [Makefile](../Makefile) provides `make dev`, `make format`, `make check`, `make test` and `make verify` shortcuts over the existing tools. Deployment is deferred.

## Current phase

The user reviewed and accepted both exploration slices for now: the first four cross-subject lessons, then reversible packet travel and editable Boolean construction. The later case/prediction/arrangement experiment and its three lessons/covers were rejected and removed. The accepted nine-lesson baseline at `f3c2fb3` is retained; two existing screens now exercise a small visual extension. [Visual exploration research](references/visual-exploration.md) now guides candidate additions; [earlier general-mechanics research](references/general-interaction-engine.md) is background, with its build order superseded. Favor simple visually led discovery; lesson subjects vary broadly and do not constrain capabilities. The Great Wave now offers an optional revealable composition guide; user review found its educational payoff unclear and calls for a better example before expansion. The camera has a paused shutter-motion schematic; user review found playback smooth but captions too fast, so the explanation now stays fixed and the illustrative cycle is slower. That engine slice added no package or lesson. The later homepage implementation adds original discovery/piano imagery and sourced NASA Moon/Earth media, with local provenance; no new dependencies or prepared lessons. The homepage is now implemented for continued user review. Latest feedback removes the generated game-forest example and duplicate rotating globe: the large Pompeii photograph was also removed after user review found it visually distracting. The showcase order is Moon → Red Fuji → flat connection map → prepared collection; image detail explanations remain inside Red Fuji. The Moon remains the sole homepage 3D exhibit. Prepared frontend review and repository alignment precede remaining M00 backend setup and M01–M09 production integration. Existing UI is reused. PostgreSQL/Drizzle, Better Auth, Mastra/Inngest, live providers, production audio, synchronized accounts, private/public sharing, community services and Premium remain future work.
